# Restaurant Reservation System

A full-stack web application that lets users book restaurant tables online. Built with the MERN stack.

**Live Demo:** https://restaurant-reservation-system-olive.vercel.app/

## Features
- Book a table by choosing date, time and number of guests
- Reservation details stored in MongoDB
- Responsive React user interface
- REST API built with Node.js and Express

## Tech Stack
| Layer | Technology |
|-------|------------|
| Frontend | React, HTML, CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB |

## Project Structure
- `client/` : React frontend
- `server/` : Node.js and Express backend

## Setup
1. Clone the repository
   `git clone https://github.com/swetakardam/restaurant-reservation-system.git`
2. Start the backend
   `cd server`
   `npm install`
   Create a `.env` file with `MONGO_URI=your_mongodb_connection_string` and `PORT=5000`
   `npm start`
3. Start the frontend (new terminal)
   `cd client`
   `npm install`
   `npm start`
